# Brief：课堂用的网页计算器

**Date:** 2026-10-09 · **Interviewed:** 陈慧（数学老师）

## Problem & consumer

某市第二中学初一到初三的学生在机房上数学课时需要一个计算器；老师在投影上演示。现有的系统计算器会把 0.1+0.2 显示成 0.30000000000000004，学生看不懂。

## Done means

- 一个网页计算器，双击本地 HTML 文件即可打开。
- 支持加减乘除、括号、负数、小数、百分号、乘方（^）和平方根（√），运算优先级正确。
- 0.1+0.2 显示 0.3。
- 错误时用中文提示：除以 0 显示"不能除以 0"，括号不配对显示"括号不配对"，负数开平方显示"负数不能开平方"，并标出出错的位置。
- 显示最近 20 条历史记录，点击可重新载入；刷新后还在；可以清空。
- 投影模式：一键放大字号。

## Where it lives

- 新建仓库 `txehq/wfe-calculator`，纯静态页面。

## Out of scope & constraints

- 不做三角函数和对数。
- 不做手机 App。
- 机房经常断网，页面要能离线打开。

## Open questions

- 技术选择由 agent 决定。
